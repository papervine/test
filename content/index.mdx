Papervine turns a Git repo of **MDX files** and a single **`docs.json`** into a fast,
beautiful documentation site. This is the **M0 renderer skeleton**: a single-tenant
happy path proving the rendering core.

## What works in M0

<Steps>
  <Step title="docs.json parsing">
    A Zod-validated, docs.json-compatible schema with a recursive navigation tree.
  </Step>
  <Step title="MDX rendering">
    Pages compile with our component set and Shiki syntax highlighting.
  </Step>
  <Step title="Navigation + TOC">
    A recursive sidebar with active states and an on-page table of contents.
  </Step>
  <Step title="Theming">
    Colors from `docs.json` drive CSS variables, with light/dark mode.
  </Step>
</Steps>

<Note>
  Multi-tenancy, Git sync, search, the API playground, and the AI assistant arrive
  in later milestones (M2–M5).
</Note>
