---
title: General
description: Rename a site — set the display name shown across the dashboard.
---

The **General** page (**Settings → General**) holds a site's basic settings. Today that is the
**project name** — the label shown across the dashboard: the site switcher and the breadcrumb.

Edit the name and **Save changes**. Only **owners and admins** can rename a site.

The name is a display label only. It is **not** the site's URL — that's the slug, which stays
fixed — and it's **not** the title rendered on the published docs, which comes from your repo's
`docs.json`.
